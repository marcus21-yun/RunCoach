## Step 3. WearMainActivity.kt — 화면 네비게이션

```kotlin
@AndroidEntryPoint
class WearMainActivity : ComponentActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContent {
            val navController = rememberSwipeDismissableNavController()
            SwipeDismissableNavHost(
                navController = navController,
                startDestination = Screen.Home.route
            ) {
                composable(Screen.Home.route)    { HomeScreen(navController) }
                composable(Screen.PreRun.route)  { PreRunScreen(navController) }
                composable(Screen.Running.route) { RunningScreen(navController) }
                composable(Screen.PostRun.route) { PostRunScreen(navController) }
                composable(Screen.AiGoal.route)  { AiGoalScreen(navController) }
                composable(Screen.History.route) { HistoryScreen(navController) }
            }
        }
    }
}

sealed class Screen(val route: String) {
    object Home    : Screen("home")
    object PreRun  : Screen("prerun")
    object Running : Screen("running")
    object PostRun : Screen("postrun")
    object AiGoal  : Screen("aigoal")
    object History : Screen("history")
}
```

### RunningScreen 핵심 구조

```kotlin
@Composable
fun RunningScreen(navController: NavController) {
    Box(modifier = Modifier.fillMaxSize().background(Color.Black)) {

        // 메인 데이터 (항상 표시)
        RunningMainData(
            distance = state.distanceKm,
            pace     = state.currentPace,
            heartRate= state.heartRate,
            diffKm   = state.diffFromLastKm
        )

        // 알람 오버레이 (조건 충족 시 2~3초간 표시)
        if (state.activeAlarm != null) {
            AlarmOverlay(
                alarm = state.activeAlarm,
                onDismiss = { viewModel.dismissAlarm() }
            )
        }

        // 종료 버튼 (화면 하단 - 길게 누르기)
        EndButton(
            modifier = Modifier.align(Alignment.BottomCenter),
            onLongPress = {
                viewModel.stopRunning()
                navController.navigate(Screen.PostRun.route)
            }
        )
    }
}
```

### AlarmOverlay — 알람 4종

```kotlin
@Composable
fun AlarmOverlay(alarm: AlarmType, onDismiss: () -> Unit) {
    val (icon, title, subtitle, borderColor) = when (alarm) {
        AlarmType.DISTANCE  -> AlarmStyle("🔔", "1 km !", "6:28/km 🟢", Color(0xFF4FC3F7))
        AlarmType.HEARTRATE -> AlarmStyle("⚠️", "심박 높음", "178bpm 줄이세요", Color.Red)
        AlarmType.SPEEDUP   -> AlarmStyle("🎯", "3 km !", "스피드 +5%", Color(0xFF4FC3F7))
        AlarmType.PACE      -> AlarmStyle("📉", "페이스 저하", "목표보다 느림", Color.Yellow)
    }

    // 2초 후 자동 닫힘
    LaunchedEffect(alarm) {
        delay(if (alarm == AlarmType.HEARTRATE) 3000L else 2000L)
        onDismiss()
    }

    Box(
        modifier = Modifier
            .fillMaxSize()
            .background(Color.Black.copy(alpha = 0.85f))
            .border(2.dp, borderColor, CircleShape),
        contentAlignment = Alignment.Center
    ) {
        Column(horizontalAlignment = Alignment.CenterHorizontally) {
            Text(icon, fontSize = 28.sp)
            Text(title, color = Color.White, fontSize = 18.sp, fontWeight = FontWeight.Bold)
            Text(subtitle, color = Color(0xFFAAAAAA), fontSize = 12.sp)
        }
    }
}
```

## Step 6. WearRunningService.kt — 실시간 센서

```
역할:
  - Health Services API로 심박수/거리/페이스 1초마다 수신
  - StateFlow로 RunningScreen에 데이터 전달
  - 러닝 완료 시 결과 JSON 만들어 폰으로 전송

주요 메서드:
  startExercise()   ← 러닝 시작 시 호출
  stopExercise()    ← 종료 시 호출 → 결과 계산
  observeMetrics()  ← 1초마다 심박/거리/페이스 업데이트
  sendResultToPhone() ← Wearable Data Layer로 폰에 전송
```

## Step 7. AlarmTriggerManager.kt — 알람 조건 판단

```
판단 로직 (RunningService에서 매초 호출):

  fun checkAlarms(metrics: RunMetrics, goal: WeeklyGoal): AlarmType? {
      if (metrics.heartRate > goal.hrAlertBpm)   return HEARTRATE  // 1순위
      if (metrics.distanceKm >= nextSpeedupKm)   return SPEEDUP    // 2순위
      if (justCrossedKm(metrics.distanceKm))     return DISTANCE   // 3순위
      if (paceDiffPct(metrics.pace, goal) > 10%) return PACE       // 4순위
      return null
  }

진동 실행:
  HEARTRATE → VibrationEffect 3회 강하게 (200ms x3)
  SPEEDUP   → 2회 중간 (150ms x2)
  DISTANCE  → 1회 짧게 (100ms)
  PACE      → 2회 (150ms x2)
```

## 주의사항

| 항목 | 내용 |
|------|------|
| 화면 크기 | Galaxy Watch 5 = 396×396px 원형 → 모든 UI 원형 기준 설계 |
| ScalingLazyColumn | 일반 LazyColumn 대신 반드시 Wear용 사용 |

| 알람 지속 시간 | 심박 경고 3초 / 나머지 2초 — 너무 길면 러닝 방해 |
| Health Services | 백그라운드 실행 시 `foregroundServiceType="health"` 필수 |
