## 워치 앱 — 화면 및 역할

### 화면 흐름
```
[워치 알림 탭]
      │
      ▼
[홈 대시보드]  ──크라운──▶  [기록 히스토리]
      │
      ▼
[러닝 시작 전]
      │
      ▼
[러닝 중] ◀── 실시간 알람 오버레이 (4종)
      │
      ▼
[러닝 후 결과]
      │
      ▼
[AI 다음 목표]
      │ 수락
      ▼
[홈 대시보드]
```

### 화면별 역할
| 화면 | 역할 | 데이터 출처 |
|------|------|------------|
| 홈 대시보드 | D-day, 이번주 목표, 지난 기록 요약 | DataStore (캐시) |
| 러닝 시작 전 | 지난주 기록 vs 오늘 목표 비교 | DataStore |
| 러닝 중 | 실시간 거리/페이스/심박/피로도, 알람 | Health Services API |
| 러닝 후 결과 | 오늘 기록, 지난주 대비 | WearRunningService 결과 |
| AI 다음 목표 | AI 분석 메시지 + 제안 목표 | 폰 AiGoalAdvisor 결과 수신 |
| 기록 히스토리 | 최근 5회 기록 리스트 | DataStore (캐시) |

## 폰 앱 — 두 가지 역할 상세

---

### 역할 A. 백그라운드 서비스

> **사용자가 직접 열지 않아도 항상 실행** — 워치와 데이터 주고받기, DB 저장, 알람 관리

#### 구성 요소

```
WearDataListenerService (Foreground Service)
  ├── 워치로부터 수신
  │     • 러닝 완료 데이터 (거리/페이스/심박/피로도/완주여부)
  │     • 요청: "다음 목표 알려줘"
  │     • 요청: "최근 기록 알려줘"
  │
  ├── 폰에서 처리
  │     • Room DB에 러닝 기록 저장
  │     • AiGoalAdvisor 실행 → 다음 목표 계산
  │     • Samsung Health SDK → 추가 건강 데이터 보완
  │
  └── 워치로 송신
        • 다음 주 목표 (WeeklyGoal)
        • 최근 5회 기록 (캐시용)
        • AI 분석 메시지

WeeklyAlarmReceiver (BroadcastReceiver)
  └── 매주 일요일 오전 7시
        → 워치에 "오늘 러닝 날!" 알림 신호 전송

SamsungHealthManager
  └── Samsung Health SDK 연동
        • 수면 점수 조회
        • 안정 심박수 조회
        • 스트레스 지수 조회
        → 피로도 보정에 활용
```

#### 데이터 흐름 (백그라운드)
```
워치 러닝 완료
      │
      ▼
WearDataListenerService 수신
      │
      ├──▶ Room DB 저장 (running_records)
      │
      ├──▶ Samsung Health 보완 데이터 조회
      │
      ├──▶ AiGoalAdvisor.calculate()
      │         └──▶ Room DB 저장 (weekly_goals)
      │
      └──▶ 워치로 전송
                • 다음 목표
                • AI 메시지
                • 최근 기록 5개
```

### 역할 B. 상세 기록 보기 (폰 UI)

> **사용자가 원할 때 열어서 깊은 분석** — 워치의 작은 화면에서 볼 수 없는 상세 데이터

#### 진입 방법
- 워치 기록 화면에서 "폰에서 자세히 보기" 탭 → 폰 앱 오픈
- 또는 폰에서 직접 앱 아이콘 탭

## Wearable Data Layer 메시지 정의

| 경로 | 방향 | 내용 |
|------|------|------|
| `/running/complete` | 워치 → 폰 | 러닝 완료 데이터 (JSON) |
| `/goal/request` | 워치 → 폰 | 최신 목표 요청 |
| `/goal/response` | 폰 → 워치 | 주간 목표 + AI 메시지 (JSON) |
| `/records/request` | 워치 → 폰 | 최근 기록 요청 |
| `/records/response` | 폰 → 워치 | 최근 5회 기록 (JSON) |
| `/alarm/weekly` | 폰 → 워치 | 일요일 아침 알림 신호 |
| `/detail/open` | 워치 → 폰 | 폰 앱 상세 화면 열기 요청 |
