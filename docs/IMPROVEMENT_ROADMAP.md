# RunCoach 기능 개선 방향

작성일: 2026-09-26

현재 로컬 프로젝트를 GitHub에 보관한 뒤 다음 세 가지 방향으로 개선한다.
아래 항목은 개발 계획이며 구현 완료를 의미하지 않는다.

## 1. 화면 개선
- 휴대폰 앱과 워치의 현재 화면 흐름을 점검한다.
- 러닝 전·중·후 핵심 정보와 조작을 정리한다.
- 워치 가독성은 `WATCH_UI_READABILITY_SPEC.md`를 기준으로 검토한다.

## 2. 웹앱과 연동
- 연동할 웹앱의 저장소, 인증 방식, 데이터 구조를 확인한다.
- 기존 Supabase SQL 및 앱·워치 동기화 코드를 검토한다.
- 사용자 식별, 러닝 기록 동기화, 오프라인 재시도와 접근 권한을 설계한다.

## 3. 차별화 기능 추가
- 기존 기획 문서의 AI 코칭, 브리핑, 페이스별 음악 추천 후보를 검토한다.
- 우선 개발할 기능과 성공 기준을 정한 뒤 작은 단위로 구현한다.

## 현재 보관 범위
- `app/`: Android 휴대폰 앱
- `wear/`: Wear OS 앱
- `core/`: 공통 모듈
- `supabase/`: 데이터베이스 SQL
- `docs/`와 루트 Markdown: 설계·기획·작업 기록
- 루트 PNG: 기존 화면 캡처
- Gradle 설정과 Wrapper

비밀 설정, 개발 도구의 로컬 설정, 빌드 결과물, 캐시와 런타임 데이터는 제외한다.
이번 작업은 소스 보관이며 앱 빌드 및 기기 동작 검증을 수행한 릴리스가 아니다.
